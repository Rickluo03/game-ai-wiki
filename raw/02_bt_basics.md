# 行為樹（Behavior Tree）核心節點與運作原理

## 什麼是行為樹？
行為樹（Behavior Tree, BT）是一種樹狀階層的決策模型，最早在《最後一戰 2》（Halo 2）中發揚光大，現已成為 Unreal Engine 等主流引擎的標準 AI 工具。它將決策拆解為獨立的「節點」，每個節點執行完畢後只會回傳三種狀態之一：**成功（Success）**、**失敗（Failure）** 或 **執行中（Running）**。

## 四大核心節點類型
1. **根節點（Root）**：整棵樹的起點，每個 Tick（遊戲更新週期）會從這裡向下發送執行訊號。
2. **複合節點（Composite Nodes）**：決定子節點的執行順序，最常見的有兩種：
   - **選擇器（Selector，符號通常為 `?`）**：從左到右依序執行子節點，**只要有一個成功就立刻回傳成功**並停止往下找（類似程式中的 `OR` 邏輯）。常用於「優先級決策」，例如：先嘗試「使用大招」，失敗才改用「普通攻擊」。
   - **序列器（Sequence，符號通常為 `→`）**：從左到右依序執行子節點，**必須全部成功才算成功**，只要中途有一個失敗就立刻中斷（類似 `AND` 邏輯）。常用於「連續步驟」，例如：「走到門前 → 開門 → 走進房間」。
3. **葉節點（Leaf Nodes）**：樹的最底層，分為負責檢查環境的「條件節點（Condition）」與實際控制角色動作的「任務/行為節點（Task / Action）」。
